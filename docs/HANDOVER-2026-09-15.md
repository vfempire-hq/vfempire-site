## 3. How the site builds now

```
npm ci                       # sharp (image variants), fontkit + wawoff2 (brand kit)
node build.mjs               # generator, shared partials on every page, sitemap from git dates,
                             # dist/ with hashed stylesheet, AVIF/WebP variants, <picture> wrappers
node build.mjs --no-images   # same without encoding (seconds); CI runs this with --check
python3 scripts/verify.py    # 65 pages, 0 issues at handover
python3 scripts/linkcheck.py # 0 broken links at handover
```

Facts that matter:

- `build.mjs` normalises the shared blocks in the SOURCE pages (nav with the Systems flyout, full footer, consent notice, favicon set, `/assets/house.js`) and extracts any inline `<script>` to `assets/page/<page>.js`. Source and `dist/` are both committed; `node build.mjs --check` fails if a build would change a tracked file. A second build after a full build leaves the tree unchanged (verified).
- The 13 templated product pages are generated from `systems/content-*.mjs` (each entry now has `titleTag`, `metaDesc`, `ogDesc`, `faq[]`, `related[]`). Edit the packs, never the generated HTML. `vf-mail` is in the generator's `HAND_MAINTAINED` set; `back-office-autopilot` is `RETIRED`. Hand-maintained product pages: fileit, fuelit, guardian-shield, mapit, snapit, nav-it, vf-mail, vf-home, vf-legacy, vf-wallet.
- Image variants are cached by mtime in `dist/assets`; a full build with cold cache takes about 10 minutes (123 sources, 234 variants).
- `dist/_headers` CSP is `script-src 'self'`; `verify.py` rejects inline scripts and inline event handlers, so never add them.
- The brand kit is generated: `node scripts/brand-kit.mjs` writes 58 files to `assets/brand/`, plus `favicon.ico`, `apple-touch-icon.png`, `site.webmanifest`. Rules in `docs/BRAND.md`; every shipped asset is listed in `docs/ASSETS.md` (`node scripts/assets-inventory.mjs`).
- `scripts/seo-pass.py <page>` adds the generic head tags and schema to a new page; `docs/PAGE-SKELETON.html` is the template for any new page.
- `node scripts/indexnow.mjs` after each deploy pings IndexNow with the sitemap (key file `<key>.txt` is served from the root).
