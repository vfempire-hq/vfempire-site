# VF Empire brand kit

Everything in `assets/brand/` is generated by `node scripts/brand-kit.mjs` from two sources of truth: the VF mark path that sits in every page's nav, and the Hanken Grotesk wordmark outlined at weight 600 with the nav's 0.16 em tracking. Do not redraw the mark, retype the wordmark or hand-edit an export. Change the script, regenerate, commit.

## The mark

Two strokes and an F: a stylised V and F on one baseline, drawn in a 24 × 24 box with the body running from y = 4 to y = 20. It is the favicon, the app icon, the avatar and the left-hand element of every lockup.

| File | Use |
|---|---|
| `vf-mark.svg` | Ink (#1d1d1f) on transparent. Print, documents, anything on a light ground. |
| `vf-mark-white.svg` | White on transparent. Dark grounds, photography, video overlays. |
| `vf-mark-blue.svg` | Core blue (#1f6ff2). Only when the mark is the single accent on an otherwise ink-and-paper layout. |
| `vf-mark-{256,512,1024,2048,4096}.png` | Ink PNG exports, transparent. |
| `vf-mark-white-{256,512,1024,2048,4096}.png` | White PNG exports, transparent. |

## Lockups

| File | Use |
|---|---|
| `vf-logo-horizontal.svg` (+ `-white`, `-blue`) | The primary logo: mark and wordmark on one baseline in the nav's proportions (mark box 1.833 × the wordmark's font size, gap 0.75 ×). Headers, email signatures, decks, partner pages. |
| `vf-logo-horizontal-{800,1600,3200,6400}.png` (+ `-white-`) | PNG exports, transparent. |
| `vf-logo-stacked.svg` (+ `-white`) | Mark centred above the wordmark. Square placements, covers, merchandise, watermarks. |
| `vf-logo-stacked-{800,1600,3200}.png` (+ `-white-`) | PNG exports, transparent. |
| `vf-wordmark.svg` (+ `-white`), `vf-wordmark-{800,1600,3200}.png` | Wordmark alone. Only next to the mark elsewhere on the same surface, or where the mark is already established (a running footer). |

## Rules

- **Clear space.** Keep a margin of at least the height of the V in the mark on every side of any lockup. Nothing else enters that space.
- **Minimum size.** Mark alone: 16 px or 4 mm. Horizontal lockup: 96 px or 24 mm wide. Below that, use the mark alone.
- **Colour.** Ink on paper is the default. White on ink, on core blue or on a render is the only other arrangement. The blue mark is an accent, never the default. Never a gradient, never an outline, never a drop shadow, never a tint of the mark.
- **Grounds.** Paper (#fbfbfd), silver (#f5f5f7), white, ink (#1d1d1f), core blue (#1f6ff2), or a house render with enough quiet area. Never on a photograph with detail behind the mark.
- **Proportions.** Never stretch, rotate, recolour per letter, add a tagline inside the lockup, or set the wordmark in another face or weight. The wordmark is Hanken Grotesk 600, upper case, tracked 0.16 em, always.
- **Company name in text.** "VF Empire" in running copy; "VF EMPIRE" only in the wordmark and in tracked kickers. The legal entity is "VF Empire Corp Ltd" (Malta, C 94160).
- **Product names.** S◉LOCK, FileIT, FuelIT, MapIT, SnapIT, NAV·IT, VF Mail, VF Wallet, VF Legacy, VF Home, Guardian Shield. Product logos, where they exist, sit apart from the house mark with the same clear space.

## Tokens

`assets/brand/tokens.json` carries the colour, type, radius, motion and logo tokens in machine-readable form for other agents, tools and templates. `house.css` is the CSS expression of the same tokens. If one changes, change the other in the same commit.

## Regenerating

```
npm ci                      # sharp, fontkit, wawoff2
node scripts/brand-kit.mjs  # writes assets/brand, favicon.ico, apple-touch-icon.png, site.webmanifest
node scripts/assets-inventory.mjs   # refreshes docs/ASSETS.md
node build.mjs              # mirrors everything into dist/
```
