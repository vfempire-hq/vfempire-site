## Rules

- Source of truth is `assets/` at the repo root; `dist/assets/` is written by `node build.mjs`, which also emits AVIF and WebP variants and wraps every png/jpg in a `<picture>` element. Never hand-edit `dist/`.
- Product renders follow the pipe naming: `pNN.webp` (hero, 896×1152), `pNN.png` (og:image), `pNN-flow.png` (flow band, 2304×1792), `pNN-mech.png` (mechanics render). A new product needs all four.
- Every content image in a page carries descriptive alt text with the product name, explicit width and height, and `loading="lazy"` below the fold. Decorative images carry `alt=""`.
- Photography is not used. Renders are white-studio, single blue accent, matching the house look (paper, ink, core blue).
- Fonts: only `hanken.woff2` and `instrument-italic.woff2` ship; the build removes anything else from `dist/fonts/`.
- Logos, icons, social images and favicons come from the brand kit in `assets/brand/` and are regenerated with `node scripts/brand-kit.mjs`; never draw a new version of the mark by hand.
