HOW IT WORKS

Route, gate, heal.
Three jobs, one engine.

Helmsman installs, tunes and pilots large open models on owned metal, and curates them like instruments. Every piece of work that enters a VF system passes the same three stages, whether the system is FileIT filing a return or a robotics lane moving a machine.

Route.

Helmsman picks the model, the tools and the context budget for each job, and batches work so one model does more per day. Routing is where utilisation is won.

Gate.

Every lane ends in a gate: screenshots, checks, evidence. Nothing ships on a model's word alone, and a failed check stops the job where it stands.

Heal.

When a model fails, a tool times out or a check is refused, the engine routes around it, retries and records what it learned. Recovery runs without a person present.

On the VF floor Helmsman supervises a fleet of specialised agents across engineering, audit, memory, security and creative lanes, on custom process lanes, all on owned machines. The harness stack gives each lane its supervision, memory and evidence discipline. The command dashboards show the operator what the engine is doing, lane by lane, and page a person when anything drifts. The glossary defines each term.

WHAT HELMSMAN IS NOT

Four things
the engine leaves out.

Four things Helmsman does not contain, so a buyer knows what arrives on the day of handover.

01

No model of its own

Helmsman ships without a model inside it. Any open model, today's or next year's, drops into the harness and inherits orchestration, memory, evaluation, recovery and control surfaces. Swap the model, keep the machine.

02

No third-party AI on user-data paths

VF systems run local models or VF's own EU GPU inference. OpenAI, Anthropic, Google and Cohere never sit on a path that touches user data, a rule every VF product inherits from the software thesis.

03

No cloud requirement

Helmsman runs local-first on hardware the owner holds. Cloud capacity is an option when a client wants it, never a requirement, and never the place your data has to live.

04

No kit to assemble

A commissioned system arrives complete: engine fitted, harness tuned, dashboards live, with documentation and training. VF built it to tolerance and stands behind it under the security posture every product ships against.

QUESTIONS

Asked.
Answered.

What is the Helmsman engine?

Helmsman is VF Empire's orchestration engine. It routes each job to an open model with the right tools and context budget, gates the output against evidence (screenshots, checks, signed responses) and self-heals when a model, a tool or a check fails. It runs the VF floor in Malta on one owned machine and ships inside every commissioned system.

Which AI models does Helmsman run?

Open models, on hardware the owner controls. Helmsman steers frontier-class open models on owned metal and treats the model as cargo: any open model, today's or next year's, drops into the harness and inherits the whole system. VF does not tie the engine to one model, because the model is the part that changes and the router, gates and self-heal loops are the parts that stay.

Does Helmsman need the cloud?

No. VF builds every system local-first: models, data and controls run on machines the owner holds. Cloud capacity is an option when a client wants it, never a requirement, and never the place your data has to live. No third-party AI provider sits on a path that touches user data.

What does "gated against evidence" mean?

Every process lane ends in a gate that checks the output against proof: a screenshot of the result, a passing test, a signed response, a registry acknowledgment. Nothing ships on a model's word alone. A failed check stops the job and sends it back through the self-heal loop, and the command dashboard shows the operator what the gate refused and why.

What happens when a model fails at 3am?

The self-heal loop handles it without a person present. Helmsman retries the step, routes around the failed model or tool, and records what it learned in an improve-queue for the next run. The recovery appears on the dashboard, and if the lane drifts beyond its tolerance the dashboard pages a person. Humans sit only at the gates that matter.

Can I commission Helmsman on its own?

Helmsman ships inside every commissioned system. VF builds complete systems to order: engine, harness, dashboards and training, on hardware you own. Write to info@vfempire.com with the problem and VF scopes the machine around it, builds it to tolerance and hands it over with documentation and training. See the build slate for what that has produced so far.
